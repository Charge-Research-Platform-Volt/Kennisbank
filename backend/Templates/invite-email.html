To access the Kennisbank, you'll first need to connect to our secure VPN network. Follow the steps below to get started.

1

Install Tailscale

Tailscale is the VPN client that securely connects you to our network. Download and install it for your operating system.

Download for Windows Download for Mac
2

Connect to the VPN

After installing Tailscale, open a terminal and run the command below to connect to the Charge network. You only need to do this once — after that, Tailscale will connect automatically.

Windows

Open PowerShell (search for it in the Start menu) and paste:
tailscale up --login-server https://vpn.charge-volt.org --authkey {{AUTHKEY}}; if ($?) { echo "Connected successfully!" }

Mac

Open Terminal (search for it in Spotlight) and paste:
sudo tailscale up --login-server https://vpn.charge-volt.org --authkey {{AUTHKEY}} && echo Connected successfully!
3

Create your account

To access the Kennisbank, you'll first need to connect to our secure VPN network. Follow the steps below to get started.

Windows
1

Install Tailscale

  1. Go to the Tailscale download page and download the .exe installer.
  2. Run the installer. It will complete automatically without any prompts.
2

Connect to the VPN

  1. Press the Windows key, type "PowerShell" and press Enter to open it.
  2. Copy the entire command below and paste it into PowerShell:
    tailscale up --login-server https://vpn.charge-volt.org --authkey {{AUTHKEY}}; if ($?) { echo "Connected successfully! You may now close this window." }
  3. Once the terminal shows "Connected successfully", close all windows and continue to step 3.

Mac
1

Install Tailscale

  1. Go to tailscale.com/download, click Download and allow the download.
  2. Open the downloaded .pkg file, leave the default destination and click Install.
  3. Enter your Mac password when prompted.
  4. Tailscale opens automatically. Click Get Started.
  5. Follow the on-screen instructions to Allow System Extension.
  6. Follow the on-screen instructions to Allow VPN Configuration.
  7. Tailscale will now start the VPN. Wait for it to finish — this may take a moment.
  8. A login prompt will appear. Skip it and keep this window open, you will need it in step 2.
2

Connect to the VPN

  1. Open Terminal: press Cmd (⌘) + Space, type "Terminal" and press Enter.
  2. Copy the entire command below and paste it into Terminal:
    /Applications/Tailscale.app/Contents/MacOS/Tailscale up --login-server https://vpn.charge-volt.org --authkey {{AUTHKEY}} && echo "Connected successfully! You may now close this window."
  3. Once the terminal shows "Connected successfully", go back to the Tailscale window and enable start with your Mac.
  4. Close all windows and continue to step 3.
3

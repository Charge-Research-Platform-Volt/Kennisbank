## Introduction
This part of the Resource Manager corresponds to the `ResourceManager.AddRelation.cs` in the backend. It is responsible for adding relations between various entities in the database, such as organisations, persons, resources, and metadata. The library provides methods for adding both single relations and multiple relations in batches.

## Organisation-Organisation Relations
To add relations between organisations, you can use the `AddOrganisationRelationshipAsync` or `AddOrganisationRelationshipRangeAsync` methods:

```csharp
// Single relation with a relation description
Guid sourceOrganisationId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Guid targetOrganisationId = Guid.Parse("e530bf18-83e0-5cf2-9529-5f36g62ff8f8");
await resourceManager.AddOrganisationRelationshipAsync(
    sourceOrganisationId,
    "Parent Company",
    targetOrganisationId
);

// Single relation using string IDs
string sourceOrganisationIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
string targetOrganisationIdString = "e530bf18-83e0-5cf2-9529-5f36g62ff8f8";
await resourceManager.AddOrganisationRelationshipAsync(
    sourceOrganisationIdString,
    "Parent Company",
    targetOrganisationIdString
);

// Single relation without a relation description
await resourceManager.AddOrganisationRelationshipAsync(
    sourceOrganisationId,
    targetOrganisationId
);

// Multiple relations with relation descriptions
Guid[] targetOrganisationIds = new Guid[] 
{
    Guid.Parse("e530bf18-83e0-5cf2-9529-5f36g62ff8f8"),
    Guid.Parse("f641cf19-94f1-6dg3-0630-6g47h73gg9g9")
};
string?[] relations = new string?[] 
{
    "Parent Company",
    "Subsidiary"
};
await resourceManager.AddOrganisationRelationshipRangeAsync(
    sourceOrganisationId,
    relations,
    targetOrganisationIds
);

// Multiple relations using string IDs
string[] targetOrganisationIdStrings = new string[] 
{
    "e530bf18-83e0-5cf2-9529-5f36g62ff8f8",
    "f641cf19-94f1-6dg3-0630-6g47h73gg9g9"
};
await resourceManager.AddOrganisationRelationshipRangeAsync(
    sourceOrganisationIdString,
    relations,
    targetOrganisationIdStrings
);

// Multiple relations without relation descriptions
await resourceManager.AddOrganisationRelationshipRangeAsync(
    sourceOrganisationId,
    targetOrganisationIds
);
```

<Callout title="Note">The difference between direct organisation relations (using `AddOrganisationToResourceAsync`) and related organisation relations (using `AddRelatedOrganisationToResourceAsync`) is that direct relations represent organisations that had a direct influence on the resource (e.g., publishers), while related organisations have an indirect connection to the resource.</Callout>

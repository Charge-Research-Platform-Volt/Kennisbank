## Introduction
This part of the Resource Manager corresponds to the `ResourceManager.Delete.cs` in the backend. It is responsible for deleting resources, entities (like a person) and metadata entries.
The library automatically handles removing all related relations when an entity is deleted to maintain database integrity.

## Delete a Resource
When deleting a resource, the Resource Manager automatically removes all relations associated with the resource. This includes:
- Resource-author relations
- Resource-organisation relations
- Resource-region relations
- Resource-source relations
- Resource-related organisation relations
- Resource-related person relations
- Resource-related source relations
- Resource-tag relations

To delete a resource, you can use the `ResourceManager.DeleteResourceAsync` method which accepts either a GUID or a string ID:

```csharp
// Delete using a GUID
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.DeleteResourceAsync(resourceId);

// Or delete using a string
string resourceIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.DeleteResourceAsync(resourceIdString);
```

The method returns a boolean indicating whether the deletion was successful.

## Delete a Person
When deleting a person, the Resource Manager automatically removes all relations associated with the person. This includes:
- Removing the person from all organisations they are part of
- Deleting all person relationships containing this person
- Removing the person as an author from all resources
- Removing the person as a related person from all resources

To delete a person, you can use the `DeletePersonAsync` method which accepts either a GUID or a string ID:

```csharp
// Delete using a GUID
Guid personId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.DeletePersonAsync(personId);

// Or delete using a string
string personIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.DeletePersonAsync(personIdString);
```

The method returns a boolean indicating whether the deletion was successful.

## Delete a Resource Type
When deleting a resource type, the Resource Manager automatically handles resources that were using this type by:
- Setting the type of all resources with this type to the "unknown" resource type

To delete a resource type, you can use the `DeleteResourceTypeAsync` method which accepts either a GUID or a string ID:

```csharp
// Delete using a GUID
Guid typeId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.DeleteResourceTypeAsync(typeId);

// Or delete using a string
string typeIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.DeleteResourceTypeAsync(typeIdString);
```

The method returns a boolean indicating whether the deletion was successful.

<Callout title="Note">When a resource type is deleted, resources that were using this type will have their type changed to the "unknown" type rather than being deleted. This preserves the resources while maintaining database integrity.</Callout>

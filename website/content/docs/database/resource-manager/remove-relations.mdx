## Introduction
This part of the Resource Manager corresponds to the `ResourceManager.RemoveRelation.cs` in the backend. It is responsible for removing relations between various entities in the database, such as organisations, persons, resources, and metadata. The library provides methods for removing both single relations and pruning all relations of a specific type.

## Organisation-Organisation Relations
To remove relations between organisations, you can use the following methods:

```csharp
// Remove a single relation between organisations
Guid sourceOrganisationId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Guid targetOrganisationId = Guid.Parse("e530bf18-83e0-5cf2-9529-5f36g62ff8f8");
bool success = await resourceManager.RemoveOrganisationRelationshipAsync(
    sourceOrganisationId,
    targetOrganisationId
);

// Remove a single relation using string IDs
string sourceOrganisationIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
string targetOrganisationIdString = "e530bf18-83e0-5cf2-9529-5f36g62ff8f8";
bool success = await resourceManager.RemoveOrganisationRelationshipAsync(
    sourceOrganisationIdString,
    targetOrganisationIdString
);

// Remove all relations where an organisation is the source
bool success = await resourceManager.RemoveAllOrganisationRelationshipsWithSourceIdAsync(
    sourceOrganisationId
);

// Remove all relations where an organisation is the target
bool success = await resourceManager.RemoveAllOrganisationRelationshipsWithTargetIdAsync(
    targetOrganisationId
);

// Remove all relations containing a specific organisation (either as source or target)
bool success = await resourceManager.RemoveAllOrganisationRelationshipsContainingIdAsync(
    organisationId
);
```

    personId,
    organisationId

bool success = await resourceManager.RemovePersonFromOrganisationAsync(
    personIdString,
    organisationIdString
);

## Resource-Related Organisation Relations
To remove related (indirect) organisation relations from resources, you can use the following methods:

```csharp
// Remove a single related organisation from a resource
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Guid organisationId = Guid.Parse("e530bf18-83e0-5cf2-9529-5f36g62ff8f8");
bool success = await resourceManager.RemoveRelatedOrganisationFromResourceAsync(
    resourceId,
    organisationId
);

// Remove a single related organisation using string IDs
string resourceIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
string organisationIdString = "e530bf18-83e0-5cf2-9529-5f36g62ff8f8";
bool success = await resourceManager.RemoveRelatedOrganisationFromResourceAsync(
    resourceIdString,
    organisationIdString
);

// Remove a related organisation from all resources
bool success = await resourceManager.RemoveRelatedOrganisationFromAllResourcesAsync(
    organisationId
);

// Remove all related organisations from a specific resource
bool success = await resourceManager.RemoveAllResourceRelatedOrganisationRelationsWithResourceIdAsync(
    resourceId
);
```

<Callout title="Note">The difference between direct organisation relations (using `RemoveOrganisationFromResourceAsync`) and related organisation relations (using `RemoveRelatedOrganisationFromResourceAsync`) is that direct relations represent organisations that had a direct influence on the resource (e.g., publishers), while related organisations have an indirect connection to the resource.</Callout>

## Resource-ResourceType Relations
To remove a resource type from a resource, you can use the following method:

```csharp
// Remove resource type from a resource
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.RemoveResourceTypeFromResourceAsync(resourceId);
```

<Callout title="Note">When removing a resource type from a resource, the system automatically assigns the "Unknown" resource type to the resource instead of leaving it without a type.</Callout>

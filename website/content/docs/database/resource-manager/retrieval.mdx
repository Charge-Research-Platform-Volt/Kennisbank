## Introduction
This part of the Resource Manager corresponds to the `ResourceManager.Retrieve.cs` in the backend. It is responsible for retrieving resources, entities (like a person), and metadata entries from the database. The library provides various methods to fetch single items, collections, paginated results, and specific properties.

## Retrieving a Resource
To retrieve a single resource, you can use the `GetResourceAsync` method which accepts either a GUID, a string ID, or a predicate expression:

```csharp
// Get by GUID
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Resource? resource = await resourceManager.GetResourceAsync(resourceId);

// Get by string ID
string resourceIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
Resource? resource = await resourceManager.GetResourceAsync(resourceIdString);

// Get by predicate
Resource? resource = await resourceManager.GetResourceAsync(r => r.Title == "Example Resource");
```

You can also include related entities and specify custom ordering:

```csharp
// Get with related entities included
Resource? resource = await resourceManager.GetResourceAsync(
    resourceId, 
    includeProperties: [ "Tags.Tag", "Authors.Person" ]
);

// Get with custom ordering
Resource? resource = await resourceManager.GetResourceAsync(
    resourceId,
    orderBy: r => r.PublicationDate,
    orderDescending: true
);
```

## Retrieving Multiple Resources
To retrieve multiple resources, you can use the `GetAllResourcesAsync` method:

```csharp
// Get all resources
Resource[] resources = await resourceManager.GetAllResourcesAsync();

// Get resources with a predicate
Resource[] resources = await resourceManager.GetAllResourcesAsync(
    predicate: r => r.PublicationDate > DateTime.Parse("2020-01-01")
);

// Get resources with related entities
Resource[] resources = await resourceManager.GetAllResourcesAsync(
    includeProperties: [ "Tags.Tag", "Authors.Person" ]
);

// Get resources with custom ordering
Resource[] resources = await resourceManager.GetAllResourcesAsync(
    orderBy: r => r.PublicationDate,
    orderDescending: true
);
```

## Retrieving Paginated Resources
For large datasets, the Resource Manager provides pagination capabilities through the `GetResourcePageAsync` method:

```csharp
// Get a specific page of resources (100 items per page by default)
Resource[] resources = await resourceManager.GetResourcePageAsync(pageIndex: 1);

// Get a custom page size
Resource[] resources = await resourceManager.GetResourcePageAsync(
    pageIndex: 2,
    pageSize: 50
);

// Get a page with a predicate
Resource[] resources = await resourceManager.GetResourcePageAsync(
    pageIndex: 1,
    pageSize: 50,
    predicate: r => r.TypeId == Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7")
);

// Get a page with custom ordering
Resource[] resources = await resourceManager.GetResourcePageAsync(
    pageIndex: 1,
    pageSize: 50,
    orderBy: r => r.Title,
    orderDescending: false
);

// Get a page with related entities
Resource[] resources = await resourceManager.GetResourcePageAsync(
    pageIndex: 1,
    pageSize: 50,
    includeProperties: [ "Tags.Tag", "Authors.Person" ]
);
```

## Retrieving Resource Properties
To retrieve a specific property of a resource without fetching the entire entity, you can use the `GetResourcePropertyAsync` or `GetResourcePropertyOrDefaultAsync` methods:

```csharp
// Get a specific property
string title = await resourceManager.GetResourcePropertyAsync(resourceId, r => r.Title);

// Get a property with a default value if not found
string? description = await resourceManager.GetResourcePropertyOrDefaultAsync(resourceId, r => r.Description);
```

## Retrieving a Person
To retrieve a single person, you can use the `GetPersonAsync` method:

```csharp
// Get by GUID
Guid personId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Person? person = await resourceManager.GetPersonAsync(personId);

// Get by string ID
string personIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
Person? person = await resourceManager.GetPersonAsync(personIdString);

// Get by predicate
Person? person = await resourceManager.GetPersonAsync(p => p.Name == "John Doe");

// Get with related entities
Person? person = await resourceManager.GetPersonAsync(
    personId, 
    includeProperties: [ "RelatedOrganisations.Organisation", "AuthoredResources.Resource" ]
);

// Get with custom ordering
Person? person = await resourceManager.GetPersonAsync(
    personId,
    orderBy: p => p.Name,
    orderDescending: false
);

// Get by predicate with custom ordering and related entities
Person? person = await resourceManager.GetPersonAsync(
    p => p.Occupation == "Researcher",
    orderBy: p => p.Name,
    orderDescending: false,
    includeProperties: [ "OwnedResources.Resource" ]
);

// Get person property
string name = await resourceManager.GetPersonPropertyAsync(personId, p => p.Name);

// Get person property with default value if not found
string? email = await resourceManager.GetPersonPropertyOrDefaultAsync(personId, p => p.EmailAddress);
```

ResourceType[] resourceTypes = await resourceManager.GetAllResourceTypesAsync(
    includeProperties: [ "Resources" ] 
);

// Get resource types with custom ordering
ResourceType[] resourceTypes = await resourceManager.GetAllResourceTypesAsync(
    orderBy: rt => rt.Name,
    orderDescending: true
);

// Get resource types with predicate and related entities
ResourceType[] resourceTypes = await resourceManager.GetAllResourceTypesAsync(
    predicate: rt => rt.Name.Contains("Media"),
    includeProperties: [ "Resources" ]
);

// Get resource types with pagination
ResourceType[] resourceTypes = await resourceManager.GetResourceTypePageAsync(
    pageIndex: 1,
    pageSize: 50
);

ResourceType[] resourceTypes = await resourceManager.GetResourceTypePageAsync(
    pageIndex: 1,
    pageSize: 50,
    orderBy: rt => rt.Name,
    orderDescending: true,
    predicate: rt => rt.Name.Contains("Document")

// Get resource types with pagination and related entities
ResourceType[] resourceTypes = await resourceManager.GetResourceTypePageAsync(
    pageIndex: 1,
    pageSize: 50,
    includeProperties: [ "Resources" ]
);

<Callout title="Note">
The Resource Manager uses default ordering for each entity type if not specified otherwise:
- Resources are ordered by creation date (descending)
- Persons are ordered by name (ascending)
- Organisations are ordered by name (ascending)
- Regions are ordered by name (ascending)
- Tags are ordered by name (ascending)
- Resource types are ordered by name (ascending)
</Callout>

## Introduction
This part of the Resource Manager corresponds to the `ResourceManager.Update.cs` in the backend. It is responsible for updating properties of resources, entities (like a person), metadata entries, and relationship properties.
The library provides methods for updating individual properties of entities in the database.

## Updating a Resource
To update a specific property of a resource, you can use the `UpdateResourceAsync` method which accepts an ID (either GUID or string), a property selector, and the new value:

```csharp
// Update resource title using GUID
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.UpdateResourceAsync(
    resourceId, 
    resource => resource.Title, 
    "Updated Resource Title"
);

// Update resource title using string ID
string resourceIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.UpdateResourceAsync(
    resourceIdString, 
    resource => resource.Title, 
    "Updated Resource Title"
);

// Update resource description
bool success = await resourceManager.UpdateResourceAsync(
    resourceId, 
    resource => resource.Description, 
    "This is an updated description for the resource."
);

// Update resource language code
bool success = await resourceManager.UpdateResourceAsync(
    resourceId, 
    resource => resource.LanguageCode, 
    "FR"
);

// Update resources matching a predicate
bool success = await resourceManager.UpdateResourceAsync(
    resource => resource.LanguageCode == "EN" && resource.PublicationDate < DateTime.Parse("2020-01-01"),
    resource => resource.Note,
    "Updated note for all older English resources"
);
```

The method returns a boolean indicating whether the update was successful.

To update a specific property of an organisation, you can use the `UpdateOrganisationAsync` method:

```csharp
// Update organisation name using GUID

    organisationId, 
    organisation => organisation.Name, 
    "Updated Organisation Name"
);

// Update organisation name using string ID
string organisationIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.UpdateOrganisationAsync(
    organisationIdString, 
    organisation => organisation.Name, 
    "Updated Organisation Name"
);

// Update organisation description
bool success = await resourceManager.UpdateOrganisationAsync(
    organisationId, 
    organisation => organisation.Description, 
    "This is an updated description for the organisation."
);

// Update organisation website
bool success = await resourceManager.UpdateOrganisationAsync(
    organisationId, 
    organisation => organisation.Website, 
    "https://updated-website.org"
);

// Update organisation email address
bool success = await resourceManager.UpdateOrganisationAsync(
    organisationId, 
    organisation => organisation.EmailAddress, 
    "updated-email@example.org"
);

// Update organisations matching a predicate
bool success = await resourceManager.UpdateOrganisationAsync(
    organisation => organisation.Website == null,
    organisation => organisation.Description,
    "Organisation with no website"
);
```

## Updating Metadata
The Resource Manager provides methods to update metadata for different resource types:

### Audio Metadata
```csharp
// Update audio URL using resource GUID
Guid resourceId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.UpdateAudioMetadataAsync(
    resourceId, 
    metadata => metadata.URL, 
    "https://updated-audio-url.com/audio.mp3"
);

// Update audio length using string resource ID
string resourceIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.UpdateAudioMetadataAsync(
    resourceIdString, 
    metadata => metadata.Length, 
    360000UL // 6 minutes in milliseconds
);

// Update audio metadata matching a predicate
bool success = await resourceManager.UpdateAudioMetadataAsync(
    metadata => metadata.Length > 3600000, // longer than 1 hour
    metadata => metadata.URL,
    "https://long-audio-files.com/"
);
```

### Video Metadata
```csharp

```

## Updating a Tag
To update a specific property of a tag, you can use the `UpdateTagAsync` method:

```csharp
// Update tag name using GUID
Guid tagId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
bool success = await resourceManager.UpdateTagAsync(
    tagId, 
    tag => tag.Name, 
    "Updated Tag Name"
);

// Update tag name using string ID
string tagIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
bool success = await resourceManager.UpdateTagAsync(
    tagIdString, 
    tag => tag.Name, 
    "Updated Tag Name"
);

// Update whether the tag is standardized
bool success = await resourceManager.UpdateTagAsync(
    tagId, 
    tag => tag.IsStandardized, 
    true
);

// Update whether the tag is approved
bool success = await resourceManager.UpdateTagAsync(
    tagId, 
    tag => tag.IsApproved, 
    true
);

// Update tags matching a predicate
bool success = await resourceManager.UpdateTagAsync(
    tag => tag.Name.Contains("legacy"),
    tag => tag.IsStandardized,
    false
);
```

<Callout title="Note">Approving and unapproving tags is handled by the methods discussed [here](#managing-tag-approvals).</Callout>

To update the relation between two organisations, you can use the `UpdateRelationInOrganisationRelationshipAsync` method:

```csharp

    sourceOrganisationId,
    "Updated Relation",
    targetOrganisationId
);

// Update relation using string IDs

string targetOrganisationIdString = "e530bf18-83e0-5cf2-9529-5f36g62ff8f8";

    targetOrganisationIdString
```

## Managing Tag Approvals
The Resource Manager provides special methods for managing tag approvals on resources:

### Approving a Tag on a Resource
To approve a tag on a resource, you can use the `ApproveTagOnResourceAsync` method:

```csharp
// Approve tag using GUIDs
Guid tagId = Guid.Parse("d429af17-72d9-4bf1-8418-4e25f51ff7e7");
Guid resourceId = Guid.Parse("e530bf18-83e0-5cf2-9529-5f36g62ff8f8");
Guid adminId = Guid.Parse("f641cf19-94f1-6dg3-0630-6g47h73gg9g9");
bool success = await resourceManager.ApproveTagOnResourceAsync(
    tagId,
    resourceId,
    adminId
);

// Approve tag using string IDs
string tagIdString = "d429af17-72d9-4bf1-8418-4e25f51ff7e7";
string resourceIdString = "e530bf18-83e0-5cf2-9529-5f36g62ff8f8";
string adminIdString = "f641cf19-94f1-6dg3-0630-6g47h73gg9g9";
bool success = await resourceManager.ApproveTagOnResourceAsync(
    tagIdString,
    resourceIdString,
    adminIdString
);

// Approve tag using mixed ID types
bool success = await resourceManager.ApproveTagOnResourceAsync(
    tagId,
    resourceIdString,
    adminId
);

bool success = await resourceManager.ApproveTagOnResourceAsync(
    tagIdString,
    resourceId,
    adminIdString
);
```

When a tag is approved on a resource, the following properties are updated:
- `IsApproved` is set to `true`
- `ApprovedBy` is set to the admin ID
- `ApprovedOn` is set to the current UTC time

## Introduction
The open file button is a component that allows users to open or download files from the knowledgebank. It is a simple and effective way to provide users with access to important documents and resources.

## Usage
The open file button can be used in various contexts, such as on the home page, archive page, or any other page where files are available for download. It is typically displayed as a button with a download icon or as button as with a label. For showing the button as an icon, the attribute isIcon must be set to true. For files opened in another page, the label will be "Open". For files that will be downloaded, the label will be "Download".

## Database structure

There are three tables in the PostgreSQL database for the Tag system:
- **tags**: This table contains the standardized tags. It has the following columns:
  - Id (GUID): The unique identifier for the tag.
  - Name (string): The name of the tag.
- **user_tags**: This table contains the user-created tags. It has the following columns:
  - Id (GUID): The unique identifier for the user tag.
  - Name (string): The name of the user tag.
  - IsApproved (bool): Indicates whether the user tag is approved by an admin.
- **doc-tag**: This table is a many-to-many relationship table that connects documents to tags. It has the following columns:
  - doc-id (GUID): The unique identifier for the document.
  - tag-id (GUID): The unique identifier for the tag.

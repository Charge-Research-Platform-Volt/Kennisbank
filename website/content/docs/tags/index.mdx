## Introduction

Tags are short text labels that can be associated with files on the knowledgebank. They serve as a way to add metadata to the files, making them easier to organize, search, and retrieve. By using tags, users can quickly identify the content of a document without having to open it.
There are two types of tags: Standardized Tags and User Tags. A Standardized Tag is a tag from a Standardized list, maintained by admins. User Tags are tags created by users.

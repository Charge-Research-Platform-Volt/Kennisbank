## Introduction

## Types in the frontend
### TagBase
**Description**: The TagBase is the base type for all tag types in the frontend.

**Fields**:
- **Name (string)**: The name of the tag.

### Tag
**Description**: The Tag is the standardized tag type in the frontend. It is used to represent a tag that is created by an admin and is used to categorize content.

**Fields**:
- **Name (string)**: The name of the tag.
- **Id (string)**: The Id is the key in the database and is used to identify the tag.

### TagsArray
**Description**: The TagsArray is an array of the Tag type. It is used to represent a list of tags that are used to categorize content.

## Tag class in the backend
**Namespace**: KnowledgeBank.Models

**Desciption**: The Tag class is used to represent a standardized tag in the backend of the knowledgebank and in the PostgreSQL database. 

**Fields**:
- **Id (GUID)**: The Id is the key in the database and is used to identify the tag.
- **Name (string)**: A unique name used to display the tag in the frontend.

title: "Archive page"
description: "Learn how to use the archive page"
---
**Author:** Rens van Moorsel
 
The archive page is the page where all the files are shown. Each file contains the following information: the name of the file, the description of the content, the type of the file, the date of when the file is created and the date of when the file is editted for the last time. 
The files can be opened or downloaded with the buttons behind the files (..).

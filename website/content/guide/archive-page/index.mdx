## Introduction
 
The archive page is the page where all the files are shown. Each file contains the following information: the name of the file, the description of the content, the type of the file, the date of when the file is created and the date of when the file is editted for the last time. 

## Opening and downloading
The files can be opened or downloaded with the buttons behind the files ({<DownloadIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />}). 

## Searching
The archive page contains a search bar. This search bar can be used to search for files. With the searchbar files can be searched. With the {<Filter className="w-5 h-5 inline align-text-bottom" fill="#777" />} icon, a filter popup opens. With this popup you can filter the search results on creation date of the file and on the tags of the files.

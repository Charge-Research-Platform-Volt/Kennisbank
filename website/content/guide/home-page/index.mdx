## Introduction
The home page is the first page that is shown when you log in. It contains a a greeting, a couple of shortcut buttons and a list with files.

## Shortcut buttons
The home page has three shortcut buttons. With the first one ("Search"), the quick search can be opened. The second one opens the "Projects" page. The thirds one ("Tags") opens the "Tags" page.

## Opening files
Below the shortcut buttons, a small list with files is shown. The files can be opened or downloaded with the buttons behind the files.

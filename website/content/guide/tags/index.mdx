## Introduction
 
Tags are short text labels that can be associated with files on the knowledgebank. They serve as a way to add metadata to the files, making them easier to organize, search, and retrieve. By using tags, users can quickly identify the content of a document without having to open it.
There are two types of tags: Standardized Tags and User Tags. A Standardized Tag is a tag from a Standardized list, maintained by admins. User Tags are tags created by users. A User Tag can also be approved. This means that an admin has reviewed the User Tag and thinks the tag is meaningful. 
A Standardized Tag can be recognized by the {<AdminIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} icon. An approved User Tag can be recognized by the {<ApprovedTagIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} icon.

## Using a Tag for a document 
A Tag can be used during the upload proces, by searching for tags and selecting them.

## Creating a Tag
Tags can be created in two different ways. The first way is in the Tags page, by typing the name for the tag and clicking the + icon. The second way is during the upload process. For this way you have to click the "Create" button on the upload page. A entry appears where the name can be filled in. By clicking "Add", the tag will be created.

## Editting a Tag
Admins can edit tags. This can be done on the Tags page by clicking the {<EditIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} button behind the tag that you want to edit.

## Deleting a Tag
Admins can delete tags. This can be done on the Tags page by clicking the {<DeleteIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} button behind the tag that you want to be deleted. 

## Approving a User Tag
Admins can approve User Tags. This can be done on the Tags page by clicking the {<ApproveTagIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} button behind the tag that you want to approve.

## Standardizing an approved User Tag
Admins can standardize an approved User Tag. This can be done on the Tags page by clicking the {<AdminIcon className="w-5 h-5 inline align-text-bottom" fill="#777" />} button behind the tag that you want to standardize.
